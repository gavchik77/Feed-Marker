# Marker Digestibility Tutor

Single-file student training app based on the supplied marker / indicator digestibility slides.

## Fixed Exercise 1
Cow consumes 6.5 kg DM hay/day.
External marker dose = 10 g Cr2O3/day.
Marker concentration in faeces = 4 g/kg faecal DM.

Students calculate:
1. faecal DM = 10 / 4 = 2.5 kg/day
2. DM digested = 6.5 - 2.5 = 4.0 kg/day
3. DMD = 4 / 6.5 × 100 = 61.5%

## Fixed Exercise 2
DM intake = 6.5 kg/day
Marker dose = 10 g/day
Marker in faeces = 4 g/kg DM
Organic matter in feed = 919 g/kg
Organic matter in faeces = 780 g/kg

Students calculate:
1. undigested fraction
2. OM digestibility coefficient (~0.674)
3. OM digestibility percentage (~67.4%)

## Practice
Two separate generators produce similar problems:
- DM digestibility from marker dose and faecal marker concentration
- compound digestibility coefficient using OM, crude protein, fibre or fat

Practice compound values are illustrative teaching values.
